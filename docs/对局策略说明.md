# 当前对局策略说明与比较

> 最后更新：2026-09-17
>
> 这份文档说的是“现在代码实际会做什么”。它不是已经证明能获胜的最佳策略；只有公司服务器真实对局才能证明策略好不好。

## 1. 一句话版本

当前程序像一个先保护家、再建设、最后赚钱的小队：

1. 有人受伤或围墙受损时，先治疗或修墙；
2. 有可升级建筑且钱够时，优先买和使用升级券；
3. 没有足够武器时，优先建造最多三座炮台；
4. 炮台完成后，用石头在基地周围建围墙；
5. 围墙计划完成后，采矿、按实时最高价卖矿；
6. 夜晚让三个角色分别靠近炮台，攻击正朝我方移动的机器人。

这套顺序来自当前 [brain.py](../Demo/CoreGeek/src/agent/brain.py) 的实际判断顺序，不是纸面计划。

## 2. 白天策略：代码一步一步会做什么

### 2.1 两名工人的顺序

每名工人在一回合只能做一件事。代码会按下面顺序检查：

1. **救人和修墙**：角色受伤且有药就先吃药；围墙受损时，工人会买或使用修墙包。
2. **升级建筑**：有升级券就去建筑旁使用；没有券、钱够、背包不满时，就去武器商店买券。优先级是：武器 > 基地 > 围墙。
3. **购买防守道具**：升级暂时做不了时，可能购买 `Bomb` 或 `DizzyWeapon`。
4. **使用召唤令**：每天白天的前 10 回合，若背包有召唤令，每回合最多由一名工人使用一张。使用顺序是 BOSS → 大型 → 中型 → 小型。代码不会主动购买召唤令。
5. **建造炮台**：没有达到三座炮台、且本回合计划金币足够时，按 加特林 → 电磁炮 → 火箭 的顺序建造。
6. **建造围墙**：炮台位置都完成后，缺围墙就优先采石头和建墙；固定留出一个入口，不把基地四周完全堵死。
7. **正常采矿和卖矿**：围墙计划完成后，工人先把背包矿石带去小贩；站在小贩旁时，优先卖当回合价格最高的矿石；没有矿石才去采石、铁、铜。

两名工人会用“已占用位置”避开同一格和同一矿点，但不能完全预测下回合机器人或敌方角色的碰撞。

### 2.2 开拓者的顺序

开拓者也会先治疗或升级。没有已接任务时，它会走到最近的有效己方任务点并发送 `acceptTask`。

一旦接口中的 `phaseTask` 有文字，说明任务已经接到。此时它会停在任务点附近，不再被派去炮台，因为任务书规定：离开任务点周围一格，任务就会结束。

当前代码还不会回答任务、调用 LLM、执行沙盒命令，或开启宝藏。这些答案和条件不能猜。

## 3. 夜晚策略：代码一步一步会做什么

1. 如果基地附近至少有两个、且目标是我方阵营的机器人，优先使用背包中的 `Bomb`；没有炸弹才使用 `DizzyWeapon`。
2. 三名角色按编号顺序和已有炮台按坐标顺序配对。角色如果不在对应炮台周围一格，就向炮台走一步。
3. 到炮台旁边后，角色操控炮台攻击。先攻击目标为我方阵营的机器人；没有这种机器人时才攻击其他可见机器人。
4. 同样危险时，优先顺序为：BOSS → 大型 → 中型 → 小型；距离更近的排在前面。
5. 加特林多目标保持在同一个 90° 扇形内；加特林和火箭会按等级补足目标数；火箭有冷却时不攻击。

## 4. 和“先建塔、围墙、挖矿升级、夜晚回基地”策略的比较

| 事情 | 当前代码策略 | 你的策略 | 比较结论 |
|---|---|---|---|
| 先建塔 | 没有可升级建筑时会优先建塔，最多三座 | 先建塔 | 大方向相同。但当前代码一旦有钱和已有建筑，可能先升级，导致第三座塔变慢。 |
| 建围墙 | 三座塔的位置完成后，优先采石并沿固定路线围墙 | 建塔后建围墙 | 大方向相同。当前代码还会留入口，避免把自己关住。 |
| 挖矿与卖矿 | 围墙计划完成后采矿；先卖背包矿石，且卖当前最高价的矿石 | 围墙后挖矿 | 大方向相同。当前代码多了“动态卖高价矿石”。 |
| 升级 | 有升级机会时排在建塔、建墙、挖矿前面 | 挖矿后升级 | 这里不同。当前代码更激进，可能防御还没成型就花钱升级；你的顺序更稳定。 |
| 夜晚前的位置 | 没有“所有人夜晚前回基地”的专门规则；夜晚开始后，角色才向各自炮台走 | 夜晚前回基地旁 | 这是你的策略更好。当前代码可能浪费夜晚前几回合赶路，错过攻击机会。 |
| 任务 | 开拓者会接任务，并在任务期间留在任务点 | 没有提到任务 | 当前代码有潜在积分来源，但任务答案尚未实现，实际收益待验证。 |
| 防守道具和召唤令 | 有条件使用炸弹、眩晕法宝和已携带召唤令 | 没有提到 | 当前代码覆盖了更多任务书道具，但什么时候买、是否划算仍需要真实对局验证。 |

## 5. 结论：建议采用的方向

你的策略适合当作主骨架：**先把防御建好，再发展经济，并且提前回到防守位置。** 它比当前代码“看到升级券就优先升级”的做法更稳。

当前代码中值得保留的部分是：动态卖高价矿石、治疗修墙、任务位置保护、目标我方的机器人优先攻击、BOSS 优先级，以及炸弹/眩晕法宝的紧急使用。

下一步最值得做的策略调整是：给白天增加“夜晚前若干回合，工人停止远距离采矿并回到炮台或基地附近”的规则；再把“是否升级”放到“三座炮台和基础围墙已完成”之后。这个调整会改变当前的资源分配顺序，需要先由你确认后再改代码。

## 6. 不能把它当作已验证胜率的原因

- 本地没有真实对手程序，无法验证夜间回防、召唤令和道具是否真的划算。
- 公司服务器才能确认建造位置、重复攻击坐标和全部道具结算是否合法。
- 任务答案、宝藏和 LLM/沙盒流程仍未实现，比赛得分能力还不完整。
